Overview

What jevlint found on 27 recorded Jev query files

A visual summary of the recorded jevlint run over 27 query files

This report shows two full passes of jevlint check over 27 query files, plus the re-send tests. The source text came from public datasets and from items written locally for this study. Each file has a known measured result, so each jevlint finding can be compared with what the source program had already measured.

Known problems found

query/overlapping-questions fired on all 5 probability files and at 0.97 on the origin file. state/oversized fired on exactly the two 20k-character documents. These match the source program’s measurements.

One probable false positive

question/refers-to-sibling fired as an error on 4 of 6 known-good MMLU files. The instruction says “the question above”, and the state is the question being answered.

Two-pass stability

23 of 27 files produced exactly the same findings in both passes. All 4 changed files changed only within 0.05 of a check’s trigger.

Exit code 0

Exit 0 means no error-severity finding, not no findings. Warnings and advice still exit 0. The first pass had 16 exit-0 files, 10 exit-1 files, and 1 exit-3 file.

Main result. jevlint found the measured failure modes in this sample. The main issue for the author is question/refers-to-sibling on standard MMLU phrasing. A single pass is enough for findings far from a trigger. Findings within 0.05 of a trigger need a repeat or a margin.

Runs & stability

Severity totals, exit codes, and which files changed between passes

The first pass is stored in reports/model_reports.json. The second pass is stored in reports/run2/. The tool’s exit code is not a finding count: exit 0 means no error-severity finding, exit 1 means at least one error, and exit 3 means the tool could not decide because a check landed within 0.05 of its trigger on different calls.

Severity totals by pass

The second pass had fewer errors and one more warning. The total number of findings stayed close: run 1 had 93 findings, run 2 had 93.

Exit codes by pass

Run 1 had one exit-3 file: q_longstate_00. The second pass resolved that file, but q_origin_overlap_00 had an unstable check and also had errors, so it exited 1.

Re-send tests

How answers moved when the question was re-sent or rewritten

On six files, the query was re-sent unchanged five times, then re-sent in small rewrites. The tool calls this jevlint probe; the transcripts are in resend-tests/. The table shows the unchanged answer, the rewrite, and the size of the change.

Rewrite change by question

The origin file has four yes/no questions that moved when asked as choices. Its choice question did not move when the options were reversed.

What moved?

A row is marked “moved” when the change cleared both 0.05 and three times the run-to-run spread measured for that row.

Re-send result. The bare yes/no “was this written by AI” question answered 0.508 over five repeats, with repeats on both sides of 0.5. The equivalent choice question answered 0.868 to 0.870 when the options were reversed. On the probability files, the two contradictory yes/no questions never moved together.

Caveats

  • 27 files. The known-good set has 6 files, so false-positive rates have wide error bars.
  • An order of magnitude more files is needed to quote a false-positive rate for a check with confidence.
  • Rubric variants, adversarial text, and generation questions were not sampled.
  • Readings move between runs. Shared findings moved by a median of and a maximum of across shared comparisons.
  • All 27 query runs completed. Raw source-program logs and exact IDs for every public-data item are not included; see SOURCES.md.
  • No API errors or rate-limit replies were observed in the recorded runs.

Reproduction

Commands and data files

Repeat the first pass and probes

python3 -m pip install "jevlint==1.2.0"
export TYPESAFE_API_KEY=...   # or TYPESAFE_KEY
python3 run_experiment.py

Run from the repository root. Requires Python 3.10+. Set JEVLINT_BENCH_RESENDS=0 to skip probes. The live model and probe calls may be billable. The script does not rerun the second pass or retries and does not rebuild this HTML snapshot.
